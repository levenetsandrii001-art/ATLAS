3. TikTok OAuth and account data

If you choose to connect TikTok, the application opens the official TikTok authorization page in your system browser. You enter credentials with TikTok, not with ATLAS. The current requested permission is user.info.basic only; this module does not make a separate profile-information request.

Authorization response
A short-lived authorization code and random state return to a temporary HTTP listener on 127.0.0.1 on your Mac. State and a per-attempt PKCE verifier are used to protect the exchange. The code/verifier/state are held in process memory and are not intentionally persisted by the module.
Token response
TikTok’s token endpoint returns an access token, refresh token, application-scoped user identifier (open_id), granted scope, token type and expiration periods. These values support account authorization and renewal. This identifier is personal data, even though the module does not request your email, phone number or password.
Application credentials
The public client key is read from local configuration. The app owner’s client secret is entered interactively and stored in Keychain. The secret, authorization code, redirect URI and PKCE verifier are sent to TikTok’s HTTPS token endpoint as needed for the exchange.
Renewal and status
An explicit refresh sends the client credentials and refresh token to TikTok. A rotated refresh token replaces the previous saved value. Local status output contains connection/expiration flags and scope, not token values or the user identifier.

The module does not request posting/upload permissions or access contacts, direct messages, follower lists or TikTok viewing history. It does not fetch videos, upload media, schedule posts or publish anything.

4. Security and token storage

The client secret and token record are stored as non-synchronizing generic-password items in the macOS login Keychain through Apple’s Security framework. They are not saved in project JSON, browser localStorage, website cookies or a plain-text token file. Keychain access is governed by macOS and the identity/permissions of the local interpreter or application.

This is a personal local integration, not a promise of hardware isolation, biometric approval for every read, or protection from all software running under your user account. Lock your Mac, secure backups and avoid sharing your login session. A future distributed app needs its own signed identity and a suitable secret-management architecture.

The callback accepts a verified one-time state, and outbound token requests use certificate-verified HTTPS with fixed endpoints and no automatic retries or redirects. Callback query strings, credentials and remote error descriptions are not intentionally written to application logs. Browser history, operating-system diagnostics and third-party infrastructure may have their own records. No method of storage or transmission is completely risk-free.

7. Retention

Local project files remain until you remove them or apply your own backup/retention policy. Uninstalling a script or deleting a video does not necessarily delete Keychain records or backups.

Keychain tokens and credentials remain until replaced or manually removed. Expiration and remote revocation stop access according to TikTok’s rules but do not automatically erase the local record. A durable “refresh outcome unknown” flag may remain after a failed renewal; it prevents automatic reuse of a possibly rotated token. The module does not automatically retry it.

PKCE/state and callback data are temporary process-memory values. Normal process exit releases that memory; this is not a guarantee of forensic erasure from operating-system storage. Support-message retention must be set before accepting public inquiries: [TO BE COMPLETED: SUPPORT_RETENTION_PERIOD_OR_CRITERIA]. Third-party retention is governed by the relevant provider.

  1. Revoke ATLAS DISCOVER’s access in TikTok’s account/app-permissions settings. The exact menu name may change; use TikTok’s current connected-app controls. The current local module does not call TikTok’s remote revoke endpoint itself.
  2. To remove the local record, open macOS Keychain Access, locate generic-password items whose service is exactly ATLAS.DISCOVER.TikTok.Desktop.v1, and remove only the corresponding ATLAS tokens: item. To remove owner credentials as well, remove the matching client-secret: item. Do not delete unrelated Keychain entries.
  3. Remove local project files and backups you no longer need. Local deletion does not remove a video already posted through TikTok or another platform; manage that content on the platform.
